# LinkedIn posts (posted manually)

Metricool's free plan does not include LinkedIn, so these are prepared each week for posting by hand on the Worsship LinkedIn page.

Each week has its own folder, for example `2026-11-week1/`, containing:

- `post.md`: the date and time to post, what to attach, and the copy to paste
- the image or PDF document to attach

Everything outside this `linkedin/` folder is scheduled automatically to Instagram and Facebook through Metricool.
