# Worsship social media assets

Public hosting for finished Worsship social media images and videos, so the scheduling tool (Metricool) can fetch them by link.

- One folder per week, for example `2026-11-week1/`
- File names follow the day and slide: `mon-1.png`, `mon-2.png`, `thu-1.png`
- Only finished, publication-ready assets go here. No personal user data, ever.
