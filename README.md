# Worsship social media assets

Public hosting for finished Worsship social media images and videos, so the scheduling tool (Metricool) can fetch them by link.

- `2026-11-week1/`, `2026-11-week2/` and so on: Instagram and Facebook posts, scheduled automatically through Metricool. File names follow the day and slide: `mon-1.png`, `thu-reel-first-video.mp4`
- `linkedin/`: LinkedIn posts to publish by hand, one folder per week with the copy in `post.md`
- Only finished, publication-ready assets go here. No personal user data, ever.
